# NORTH

## Personal Finance Intelligence Platform

NORTH is a modern finance analytics platform designed to provide clarity into personal spending, savings, and financial behavior through intelligent insights and refined data visualization.

Built with Python, Streamlit, Plotly, and machine learning, the platform combines financial tracking with a minimal enterprise-grade user experience.



## Overview

NORTH enables users to:

- Track income and expenses
- Analyze spending patterns
- Monitor savings performance
- Visualize financial trends
- Receive AI-assisted transaction categorization
- Evaluate overall financial health

The platform focuses on simplicity, clarity, and structured financial awareness.



## Core Features

- Interactive analytics dashboard
- Expense and income management
- Machine learning–based category prediction
- Financial health scoring
- Savings goal tracking
- Trend and category visualizations
- Persistent CSV-based transaction storage
- Dark-mode luxury fintech interface

## Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/north.git

cd north

Install dependencies:

pip install -r requirements.txt

Run the application locally:

streamlit run app.py

## Machine Learning Pipeline

The platform uses TF-IDF vectorization and logistic regression to intelligently classify transactions based on user-entered descriptions.

Example classifications include:
- Food & Dining
- Transport
- Bills
- Shopping
- Salary
- Freelance Income
